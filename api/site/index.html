In drei Schritten verbunden

REST findet den Spielserver. Danach kommuniziert der Client direkt mit ihm über eine einzige WebSocket-Verbindung.

  1. Verfügbare Spielserver abrufen

    Rufe GET /api/servers am Verzeichnisserver auf. Die Serverliste ist öffentlich und liefert unter anderem host und port.

  2. WebSocket zum ausgewählten Server öffnen

    Nutze ws://{host}:{port}/game. Der Spielserver antwortet zunächst mit SERVER_INFO.

  3. CONNECT senden und Bestätigung abwarten

    Sende innerhalb von 10 Sekunden CONNECT. Bewahre das Token aus CONNECT_ACK für einen späteren Reconnect auf.

{
  "type": "CONNECT",
  "data": { "username": "Alice" }
}

Ein Vertrag für alle Teams

Die YAML-Dateien sind die Grundlage der Referenz und können direkt in andere Werkzeuge importiert werden. Die REST-Referenz enthält Swagger-Testfunktionen; die WebSocket-Referenz beschreibt den Nachrichtenvertrag.
